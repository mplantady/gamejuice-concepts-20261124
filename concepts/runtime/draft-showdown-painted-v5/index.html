About this comparison

These are independent 45-second runs with different real outcomes. The original run makes seven choices and wins one round. The enhanced run makes seven choices and loses two rounds. Neither is presented as a complete match victory.

The retained original run uses its native random generator initialized with seed 1719. The enhanced run uses its untouched random draws. No results, poses or combat events were generated for this comparison.

The soundtrack comes only from the enhanced playable. The original recording has no audio track, and its saved recording report includes an audio-decode error. This comparison does not certify the original audio. Technical signal checks passed; subjective listening was unavailable.
